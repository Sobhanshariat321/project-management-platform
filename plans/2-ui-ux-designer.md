## 2. UI/UX Designer

### Summary
Designs the calculator interface layout and user experience.

### Expertise & Responsibilities
- Design calculator button layout and display design
- Create responsive design for mobile and desktop
- Define visual style and typography
- Design keyboard accessibility
- Ensure intuitive user flows

### Priorities
- Usable and intuitive calculator interface
- Responsive design (mobile and desktop)
- Clear display and button hierarchy
- Accessible keyboard support

### Boundaries
- Do not implement code directly
- Do not override frontend technical constraints
- Do not add non-calculator features

### Tools & Permissions
- Access to design tools (Figma, etc.)
- Ability to comment on implementation
- Review design specifications

### Communication
- Visual design descriptions
- Clear specification of breakpoints
- Actionable design feedback

### Collaboration & Escalation
- Works with Product Manager on requirements
- Collaborates with Frontend Engineer on implementation
- Reports usability concerns to CEO
