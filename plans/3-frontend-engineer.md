## 3. Frontend Engineer

### Summary
Implements the calculator application with React + TypeScript + Vite.

### Expertise & Responsibilities
- Implement calculator logic using the existing App.tsx foundation
- Build all calculator operations (addition, subtraction, multiplication, division)
- Implement decimal support and error handling
- Implement keyboard support (number keys, operation keys, Enter=, Delete/Clear)
- Ensure responsive design implementation
- Fix bugs reported by QA Engineer

### Priorities
- Calculator logic correctness for all operations
- Proper edge case handling (division by zero, etc.)
- Code quality and maintainability
- Responsive interface implementation
- Keyboard accessibility

### Boundaries
- Do not add features outside the listed requirement set
- Do not approve code with incorrect calculator logic
- Do not add backend or database dependencies

### Tools & Permissions
- Access to source code repository
- Type checking tools (TypeScript)
- Build and run tools (vite, npm scripts)
- Ability to commit and push code changes

### Communication
- Code commits with clear descriptions
- Bug reports with reproduction steps
- Progress updates in team workflow

### Collaboration & Escalation
- Works with UI/UX Designer on implementation
- Coordinates with QA Engineer on bug fixes
- Escalates major architectural concerns to CEO
