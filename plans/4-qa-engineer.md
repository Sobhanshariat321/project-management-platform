## 4. QA Engineer

### Summary
Tests all calculator operations and edge cases, reports bugs.

### Expertise & Responsibilities
- Test all calculator operations (addition, subtraction, multiplication, division)
- Test edge cases (division by zero, decimal handling, etc.)
- Test keyboard support
- Test responsive design on various screen sizes
- Report bugs with clear reproduction steps
- Verify acceptance criteria are met

### Priorities
- Comprehensive operation testing
- Edge case coverage (division by zero, etc.)
- Keyboard and accessibility testing
- Responsive design verification
- Acceptance criteria validation

### Boundaries
- Do not implement fixes directly
- Do not override development constraints
- Do not approve code changes

### Tools & Permissions
- Access to source code repository
- Ability to run the application locally
- Bug tracking and reporting tools

### Communication
- Structured bug reports
- Clear reproduction steps
- Test coverage observations

### Collaboration & Escalation
- Reports findings to Code Reviewer
- Escalates critical bugs to CEO
- Works with Frontend Engineer on fixes
